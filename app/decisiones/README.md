# Decisiones de GaleCore (ADRs)

Decisiones de producto de la plataforma: estrategias, analytics, datos, backend/front. Las de proceso de desarrollo viven en el workspace; las de GaleCore-AI en `GaleCore-AI/docs/decisions/`.

Una decisión por archivo, con frontmatter. Nunca se reescribe: se supersede con un archivo nuevo.

```yaml
---
id: D-0001
title: ...
date: 2026-09-16
status: vigente | superada
supersedes: [D-xxxx]     # opcional
contradicts: [D-xxxx]    # opcional, si convive con otra en tensión
scope: galecore
---
```

Cuerpo: contexto → decisión → consecuencias → evidencia (links).
