# GaleCore

GaleCore es el sistema de un trader: datos de mercado, cálculos, riesgo, estrategias en SHADOW y un monitor (galecore-app/, .NET + React), un conjunto de skills, agentes y memoria en Python (galecore-ai/) y el Lab, la terminal de chat que arma el contexto de cada turno (galecore-lab/, Node). Carpetas: galecore-app/, galecore-ai/, galecore-lab/. Instalación: ver [install/LEEME.md](install/LEEME.md).
