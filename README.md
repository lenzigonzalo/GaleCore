# GaleCore

GaleCore es el sistema de un trader: datos de mercado, cálculos, riesgo, estrategias en SHADOW y un monitor (app/, .NET + React), un conjunto de skills, agentes y memoria en Python (ai/) y el Lab, la terminal de chat que arma el contexto de cada turno (lab/, Node). Carpetas: app/, ai/, lab/. Instalación: ver [install/LEEME.md](install/LEEME.md).
